# Apex Sensitivity Lab

這是可直接部署到 GitHub Pages 的單頁版。

## GitHub Pages 部署
1. 在 GitHub 建立一個新的 Public repository，例如 `apex-sensitivity-lab`
2. 上傳此資料夾內的 `index.html`
3. 進入 repository 的 **Settings → Pages**
4. 在 **Build and deployment**：
   - Source 選 `Deploy from a branch`
   - Branch 選 `main`
   - Folder 選 `/(root)`
5. 儲存後等待約 1–3 分鐘
6. 網址通常會是：
   `https://你的GitHub帳號.github.io/apex-sensitivity-lab/`

## Brave
開啟網站後：
1. 按「開始測試」
2. 再點一次測試場地
3. Brave 會使用 Pointer Lock 鎖定滑鼠
4. 按 Esc 可解除
